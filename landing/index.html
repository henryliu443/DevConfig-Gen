DevConfig-Gen

A local, provider-based engine for generating and validating structured configuration.

Read the Documentation Source on GitHub Architecture

About

DevConfig-Gen merges multiple JSON/YAML inputs, applies overrides, validates every field with precise path diagnostics, and produces deterministic JSON, YAML, or .env artifacts through a small provider contract — with no network or system side effects.

Highlights

  • Three built-in providers: custom, json, env
  • Multi-source deep merge & --set overrides
  • Precise, path-aware validation diagnostics
  • CLI, terminal wizard, and local Web studio
  • Deterministic JSON / YAML / .env output
  • Zero runtime dependencies
  • Pluggable by design: the Provider is the only extension point

Extensibility

One extension point: the Provider. Register a provider to add a domain transformation, and the CLI, terminal wizard, and Web studio pick it up with no code changes. Even WebUI field rendering is table-driven — a provider can ship custom widgets through the optional web_ui_widgets() method, served at GET /api/widgets and registered into the same widget table.

Providers that do not implement the optional hooks behave exactly as before: the core stays provider-neutral, and domain-specific providers live in downstream forks — never in the core.
